# Approval Required

Original, self-initiated local two-player interaction prototype by Kai Zhang, created on 2026-10-10. It is a new work sample, not a past client commission, an existing studio's game, or evidence of tested audience response.

Five short rounds use two keys or on-screen buttons. The player first learns an urgent stamp cue, then receives a visually clear instruction to withhold the same action. Early inputs stamp a clerk's forehead; nearly simultaneous correct inputs earn a shared bonus. Deliberately overformal feedback makes player mistakes visible to spectators, and a restrained synthesized sound motif changes with the outcome. The final ceremonial tone ends in an anticlimactic low note.

This tests one interaction and its menu/visual/audio feedback. It does not demonstrate online multiplayer, production music or voice acting, a complete party game, or confirmed humor effectiveness with an audience. It uses original inline vector drawings and built-in browser audio, with no customer assets or external dependencies. Sound starts off and is optional. Reduced-motion preferences disable the decorative animations.

Open `index.html`, select Begin shift, and use F/J or tap the buttons. A shift takes approximately 23 seconds. Restart cancels outstanding round timers and resets both scores. Sound can be enabled with the separate control after a user gesture.
